# minista issue #145

The github repository of minista has an issue:

- [CSS Modules imported by SSG pages are omitted from pluginBundle output #145](https://github.com/qrac/minista/issues/145)

>## Description
>A CSS Module imported by a statically rendered page is used to generate hashed class names in the HTML, but its CSS is not included in the production bundle generated by pluginBundle().

The issue was opened and closed soon in aug 2026. @qrac wrote:

>CSS modules should be automatically included in the pluginBundle() import.
>This has been fixed in v4.0.10.

I, kazurayam, encountered a problem in my project which looked very similar to the above issue. So I studied the discussion.

In fact, I am not yet very happy.

1. My problem in my project still exists using the minista v4.0.11.

2. I tried to reproduce the original case of @AhmetshaLee using the minista v4.0.9. I saw, the CSS module was automatically included in the output `bundle-XXXXXXXX.css`. I failed to reproduce the case.
